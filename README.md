# Note

#### DOM - Document Object Model

- là mô hình biểu diễn cấu trúc của 1 trang HTML, giúp thay đổi css, content, event ...
- cấu trúc cây: Node, Element, Event

#### Thuộc tính (attribute)

- Là các thuộc tính của thẻ HTML, được định nghĩa trong thẻ HTML
- Ví dụ: id, class, title, style, ...

#### Thuộc tính (property)

- Là các thuộc tính của thẻ HTML, được định nghĩa trong thẻ HTML
- Ví dụ: id, class, title, style, ...

#### JSX -> JavaScript XML

- là 1 cú pháp giúp viết HTML trong Javascript
- sử dụng {} để thể hiện biến của JS

#### <React.Fragment>

- nếu để các thẻ khác nhau tại cùng 1 JSX thì sẽ bị lỗi
- dùng để gộp các loại thẻ khác nhau tại cùng 1 JSX cha (thay vì dùng thẻ div)

#### Component

- là một Hàm trong JS
